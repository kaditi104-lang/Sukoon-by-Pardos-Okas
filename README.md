## 🚀 Instant Deployment (GitHub Pages)
This repository is 100% static (HTML5, Vanilla CSS, Vanilla JavaScript).
1. Go to repository **Settings** > **Pages**.
2. Select **Source:** `Deploy from a branch`.
3. Choose branch `main` (or `master`) and folder `/(root)`.
4. Click **Save** — your site will be live instantly!
